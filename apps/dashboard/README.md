# OnboardBuddy Dashboard

This folder is reserved for the future SaaS dashboard.

Planned paid features:

- Visual tour builder
- Hosted remote config publishing
- Analytics dashboard
- Project keys and SDK configuration
- Team permissions
- Tour versioning
- A/B testing
- White-label/custom branding controls
- Audience targeting and scheduling
- Billing

The MVP intentionally keeps this app as a placeholder while the reusable React package and seller dashboard demo prove the core product experience.
