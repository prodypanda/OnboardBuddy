# Roadmap

## MVP complete

The current MVP includes:

- React package.
- Next.js seller dashboard demo.
- 5-step character-guided onboarding.
- JSON editor preview.
- Form editor preview.
- Mock remote-config loading.
- Analytics event foundation.
- Built-in placeholder character.
- Custom image URL support.
- Split character and moving hand image support.
- Shoulder-pivot hand shake.
- Pointer anchor positioning.
- Overlay modes.
- Animations.
- localStorage completion.
- Event callbacks.
- Mobile fallback behavior.
- Documentation and wiki.

## Product vision

OnboardBuddy should become a product onboarding platform where teams can:

1. Create a branded character guide.
2. Point that guide at real product UI.
3. Publish tours without code changes.
4. Measure where users start, skip, and finish.
5. Improve activation through visual, friendly onboarding.
